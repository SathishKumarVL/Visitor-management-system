# Privacy

## Principles

- Collect only visitor data needed for facility access and security
- Encrypt sensitive identity numbers at rest
- Mask ID numbers in routine UI for unauthorized roles
- Do not log full ID numbers, passwords, or crypto keys
- Visitor photos are private authenticated assets

## Retention (foundation)

Configure retention policies before enabling automatic deletion:

- Visitor profile retention
- Photo retention
- Document retention
- Audit retention

No automatic historical deletion is enabled by default in this release.

## Rights & operations

Tenant admins should eventually support:

- Export
- Anonymization
- Secure deletion where legally required

These workflows require explicit admin authorization.
