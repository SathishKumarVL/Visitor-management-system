# User Guide — TIAANO VMS

## Reception tablet

1. Login as `reception`
2. Use **Reception Mode** large buttons
3. **New Visitor** → complete 7-step wizard (under ~2 minutes)
4. After host approval → **Check In** → **Print Pass**
5. Use **Currently Inside** / **Check Out** as visitors leave
6. **Expected Visitors** → Check In when pre-registered guests arrive

## Security tablet

1. Login as `security`
2. **Scan Pass** with camera QR reader
3. Verify visitor / check out
4. Invalid codes show **INVALID VISITOR PASS**
5. Already exited visits show **VISITOR ALREADY CHECKED OUT**

## Host

1. Login as `host`
2. Review **Pending Visitor Requests**
3. **Approve** or **Reject** (reason required)

## Admin

- Dashboard statistics & charts
- Users, departments, hosts, purposes, locations
- Settings (logo path, approval/photo requirements, long-stay warning)
- Reports (Excel / PDF / CSV)
- Audit log (read-only)

## Visitor pass

Printed pass includes TIAANO branding, photo, visitor/host/department/purpose/location, visit ID, check-in time, and QR (pass identifier only).
